Practical 1: Loading & Displaying Images

Run this practical in Google Colab

Objective

To learn how to load, display, and inspect digital images using client-side image processing in the browser.

Theory: A digital image is a 2D matrix of pixel intensity values. For an 8-bit grayscale image, each pixel holds a value between 0 (black) and 255 (white). Understanding image representation is the foundation of all image processing.
  • Each pixel stores an integer intensity in the range [0, 255].
  • The image dimensions (width × height) define its spatial resolution.
  • Statistical measures (min, max, mean, std) summarize the intensity distribution.

Part 1: Load and Display a Single Image

Load the selected image in grayscale and display it with its properties (shape, data type, min/max intensity, mean, and standard deviation).

Part 2: Pixel Intensity Histogram

Visualize the distribution of pixel intensities. The histogram shows how many pixels have each intensity value (0–255), revealing the contrast and brightness characteristics of the image.

Part 3: Display Multiple Images

Display four sample images side by side in a 2×2 grid to compare different types of digital images.

Analysis Questions

  1. What does the shape of the image array represent? How do grayscale and color images differ in their array dimensions?
  2. Why do we specify cmap='gray' when displaying grayscale images in Matplotlib? What happens if we omit it?
  3. Compare the histogram distributions of two different images. What does a narrow histogram versus a wide histogram indicate about the contrast of an image?
