Practical 1: Loading and Displaying Images

1.1 Objective

To learn how to load, display, and inspect digital images using OpenCV and Matplotlib.

Theory: A digital image is a 2D matrix of pixel intensity values. For an 8-bit grayscale image, each pixel holds a value between 0 (black) and 255 (white). Understanding image representation is the foundation of all image processing.

1.2 Part 1: Load and Display a Single Image

Load a grayscale image using cv2.imread() and display it using plt.imshow() with cmap='gray'. Print the image shape, data type, and intensity range.

1.3 Part 2: Pixel Intensity Histogram

Visualize the distribution of pixel intensities using plt.hist() with 256 bins. The histogram reveals the contrast characteristics and dynamic range of the image.

1.4 Part 3: Display Multiple Images

Load 4 images from the dataset and display them in a 2×2 subplot grid using plt.subplots(2, 2). Each subplot displays the image name and its dimensions.

Analysis Questions

  1. What does the shape of the image array represent? How do grayscale and color images differ in shape?
  2. Why do we specify cmap='gray' when displaying grayscale images? What happens if we don't?
  3. Compare the histogram distributions of two different images. What does a narrow histogram vs. a wide histogram indicate about the image?

Practical 2: Impact of Sampling Rate on Spatial Resolution

2.1 Objective

To evaluate the relationship between the sampling rate (N) and spatial resolution in digital images.

Problem Statement: Spatial resolution represents the size of the smallest perceptible detail in an image and is fundamentally dependent on the sampling rate. A decrease in the number of samples (N) results in a loss of geometric detail. In this experiment, the student simulates progressive spatial resolution reduction and analyzes the resulting artifacts.

2.2 Part 1: Progressive Downsampling

The image is resized to a 1024×1024 baseline, then progressively halved 5 times using cv2.INTER_AREA interpolation: 1024 → 512 → 256 → 128 → 64 → 32.

2.3 Part 2: Comparison Plot

All resolution levels are displayed in a single comparison figure to visually assess the progressive loss of detail at each downsampling step.

2.4 Part 3: Quality Loss Visualization

Each downsampled image is resized back to 1024×1024 using bilinear interpolation to reveal the quality degradation. This demonstrates that information lost during downsampling cannot be recovered.

Analysis Questions

  1. Artifact Identification: At which resolution (N) do aliasing artifacts (jagged lines) become visible to the eye? Explain how this correlates to the sampling rate.
  2. Sensitivity Analysis: Theory suggests spatial resolution is more sensitive to shape variations than lighting variations. Compare the detail in textured areas vs. smooth areas; which loses perceptible detail first?
  3. DPI Correlation: If the physical size of the image remains constant while the pixel count is halved, how does this affect the Dots Per Inch (DPI)? Relate this to the blocky appearance of lower-resolution images.

Practical 3: Image Negation, Subtraction, and Inversion

3.1 Objective

To implement and analyze fundamental intensity transformation operations: image negation, image subtraction, and intensity inversion.

Theory: Intensity transformations are point operations that modify pixel values individually. Negation reverses the intensity scale: s = (L−1) − r, useful for enhancing detail in dark regions. Image subtraction g = |f1 − f2| reveals differences between two images, widely used in medical imaging (Digital Subtraction Angiography).

3.2 Part 1: Image Negation (s = 255 − r)

Compute the negative of a grayscale image by inverting all pixel intensities. Display the original and negative side by side with their histograms to observe the intensity transformation.

3.3 Part 2: Image Subtraction |Img1 − Img2|

Compute the absolute difference between two related images to reveal hidden structures. Applications include Digital Subtraction Angiography (mask vs. live), dental X-ray comparison, and tungsten filament shading correction.

3.4 Part 3: Complete Pipeline

Run the full pipeline on an image pair: subtraction to extract differences, negation of the result for enhanced visibility, and contrast stretching for final enhancement.

Analysis Questions

  1. In the angiography example, what structures become visible after subtraction that were not visible in either original image?
  2. Why is absolute difference used instead of simple subtraction? What would happen with signed vs. unsigned arithmetic?
  3. Compare the histogram of the original image with its negative. What mathematical relationship exists between them?

Practical 4: Gamma Correction and Power Law Transformations

4.1 Objective

To understand and implement power law (gamma) transformations for image contrast enhancement.

Theory: The power law transformation s = c · rγ is one of the most important intensity transformations. With γ < 1, dark regions are enhanced (brightening). With γ > 1, bright regions are compressed (darkening). Setting γ = 1, c = 1 produces the identity transform.

4.2 Part 1: Apply Gamma Correction

Apply the power law transformation with adjustable γ and constant c. Compare the original and corrected images with their histograms to observe the intensity redistribution.

4.3 Part 2: Gamma Series Comparison

Compare the effect of multiple gamma values (γ = 0.3, 0.5, 1.0, 1.5, 2.5, 5.0) on a single image displayed in a comparison grid.

4.4 Part 3: Log Transformation

Apply the logarithmic transformation s = c · log(1 + r) and compare its result with gamma correction at γ = 0.4 on the same image.

4.5 Part 4: Contrast Enhancement

Enhance dark images using γ < 1 (values 0.3, 0.4, 0.6) or compress bright images using γ > 1 (values 3.0, 4.0, 5.0). Compare across images with low, medium, and high contrast.

Analysis Questions

  1. For a dark image, which gamma value produces the best visual enhancement? Why does γ < 1 brighten dark regions?
  2. Compare log transformation with γ = 0.4 on the same image. Which produces better results and why?
  3. How does gamma correction relate to display devices? If a monitor has γ = 2.5, what pre-correction gamma should be applied?
